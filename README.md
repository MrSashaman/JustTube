# JustTube Downloader v1.0 

**JustTube Downloader** — это легковесное и быстрое десктопное приложение с открытым исходным кодом для скачивания видео и аудио с YouTube. Программа имеет современный графический интерфейс, написанный на `CustomTkinter`, работает в многопоточном режиме (интерфейс не зависает во время загрузки).

---

## ✨ Особенности

- **Максимальное качество:** Автоматически подтягивает и склеивает видео и аудио в наилучшем доступном качестве (1080p, 2K, 4K и выше) через `yt-dlp`.
- **Выбор контейнера (формата):** Прямо в настройках можно выбрать желаемый формат выходного файла (`MP4`, `WEBM`, `MKV`, `AVI`).
- **Современный GUI:** Интерфейс приложения поддерживает как темную, так и светлую тему оформления.
- **Обход блокировок YouTube:** Интегрирована поддержка внешних JS-рантаймов (`Node.js`/`Deno`) для успешного решения JavaScript-челленджей YouTube и сигнатур (EJS), что исключает падение скорости и ошибку 403.

---

## 🛠 Требования к системе

Для корректной работы расшифровки алгоритмов YouTube в вашей системе должен быть установлен один из JavaScript-интерпретаторов:
- **Node.js** (версия 22.0.0 или новее)
- **Deno** (рекомендуется, версия 2.3.0 или новее)

### Установка зависимостей в Ubuntu/Debian:
```bash
sudo apt update
sudo apt install nodejs ffmpeg
```
*(Компонент `ffmpeg` необходим для слияния видео и аудио потоков высокого качества в один файл).*

## 💻 Установка и запуск из исходного кода

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/MrSashaman/JustTube.git
   cd JustTube
   ```

2. Установите необходимые Python-библиотеки:
   ```bash
   pip install customtkinter yt-dlp
   ```

3. Запустите приложение:
   ```bash
   python main.py
   ```

---

## 📦 Сборка в один исполняемый файл (Build)

Программу можно скомпилировать в один самостоятельный бинарник, который будет запускаться без установленного Python.

### Для Linux (Ubuntu):
1. Установите PyInstaller: `pip install pyinstaller`
2. Запустите сборку:
   ```bash
   pyinstaller --onefile --windowed --collect-all customtkinter --name JustTube main.py
   ```
3. Готовый файл появится в папке `dist/JustTube`. 

### Для Windows:
Выполните ту же команду в командной строке Windows (PowerShell/CMD). В папке `dist/` создастся готовый файл `JustTube.exe`.
